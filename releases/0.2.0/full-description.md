[b]LIB BA Unified UI[/b]

Shared vanilla-style user-interface library for Big Ambitions mods.

This is a dependency mod. It does not add gameplay by itself. Subscribe to it and enable it in the in-game [b]Mods[/b] menu when another mod lists [b]LIB BA Unified UI[/b] as required.

[b]Included UI services[/b]

[list]
[*]Vanilla-style panels, headers, buttons, lists, search fields and popups
[*]Reusable fluent layout builders with automatic panel sizing
[*]Draggable windows with native cursor, screen clamping and saved positions
[*]Automatic hiding while the game's Options screen is open
[*]Configurable keyboard shortcuts with complete chord conflict detection
[/list]

[b]Installation[/b]

[list]
[*]Subscribe to this library and the mod that requires it
[*]Enable both Workshop items in Big Ambitions' Mods menu
[*]Restart the game after either item updates
[/list]

[b]For mod developers[/b]

Reference the stable [code]LIB_BaUnifiedUI[/code] assembly from your asmdef. Do not copy the DLL into your own [code]Dependencies[/code] folder. Source and integration documentation are available on GitHub.
